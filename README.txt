# Ankita Swain - Personal Portfolio

A beginner-friendly responsive portfolio built with only HTML, CSS and JavaScript.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html`.
3. Use Live Server in VS Code, or open `index.html` directly in a browser.

## Files

- `index.html` - page structure and content
- `style.css` - responsive design and animations
- `script.js` - mobile menu, active navigation, form validation and back-to-top button
- `images/profile.jpg` - original profile photo
- `images/project1.svg`, `project2.svg`, `project3.svg` - project card visuals
- `resume/Ankita_Swain_Resume.pdf` - resume linked to the Resume section

## Before publishing

Replace any project links or descriptions that you want to update. The contact form validates the fields and then opens the visitor's default email application using `mailto:`.
